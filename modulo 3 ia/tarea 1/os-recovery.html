Seleccione un módulo operativo para acceder al protocolo de instalación.

Windows 11 X64_UEFI

1. Crear USB Booteable
Descarga la herramienta Media Creation Tool de Microsoft. Inserta una memoria USB de al menos 8GB, ejecuta la herramienta, selecciona "Crear medios de instalación" y elige la unidad flash USB. Advertencia: Los datos de la USB serán borrados.
2. Configuración BIOS/UEFI
  1. Reinicia y presiona F2/DEL repetidamente.
  2. Asegúrate de que Secure Boot esté habilitado (Requisito estricto W11).
  3. Habilita el módulo fTPM o TPM 2.0.
  4. En Boot Priority, pon tu memoria USB como número 1.
3. Instalación Base
Inicia desde la USB. Selecciona Idioma y Teclado. Haz clic en "Instalar ahora". Selecciona la versión para la cual tienes licencia. Elige instalación "Personalizada". Formatea la partición principal e instala. Al reiniciar, remueve la USB.

Windows 10 X64_LEGACY/UEFI

1. Crear USB Booteable
Alternativamente a MCT, puedes descargar la ISO de Windows 10 y usar Rufus. Selecciona Esquema de Partición GPT para placas base modernas o MBR para equipos antiguos. Sistema de archivos NTFS.
2. Configuración BIOS/UEFI
  1. Reinicia e ingresa a BIOS.
  2. Si creaste la USB con Rufus en MBR, habilita el modo CSM / Legacy.
  3. Si la creaste en GPT, desactiva CSM y usa UEFI mode.
  4. Guarda los cambios (F10) e inicia desde la USB.
3. Instalación Base
Proceso idéntico a W11 pero no requiere conexión a internet forzosa en la configuración inicial ("OOBE"). Puedes seleccionar "No tengo internet" para crear una cuenta local directamente.

Ubuntu 24.04 LTS_LINUX

1. Crear USB Booteable
Recomendamos usar Ventoy o BalenaEtcher. Con Ventoy, solo instalas el programa en la USB una vez, y luego arrastras la ISO descargada de Ubuntu directamente a la memoria sin descomprimir.
2. Configuración BIOS/UEFI
  1. Ingresa a la BIOS.
  2. Desactiva Secure Boot (necesario para drivers privativos de NVIDIA/Wi-Fi).
  3. Si tienes discos en modo RAID (Intel RST), cámbialos a modo AHCI o Linux no detectará el disco duro.
3. Instalación Base
Elige "Try Ubuntu" o "Install". En el instalador, puedes optar por borrar todo el disco o instalar junto a Windows (Dual Boot). Selecciona "Instalar programas de terceros" para drivers Wi-Fi y codecs multimedia.

Linux Mint 21 CINNAMON

1. Crear USB Booteable
Descarga la ISO (edición Cinnamon recomendada para ex-usuarios de Windows). Usa Rufus y graba en modo DD o ISO (Rufus sugerirá el mejor método).
2. Configuración BIOS/UEFI
  1. Activar modo UEFI preferiblemente.
  2. Desactivar Fast Boot en BIOS y en Windows (si haces dual boot).
  3. Seleccionar la USB en el menú de arranque rápido (F12, F8 o F11 dependiendo de la placa base).
3. Instalación Base
Entorno muy amigable. Haz doble clic en el ícono "Install Linux Mint" del escritorio en vivo. Configura zonas horarias, distribución del teclado y particionamiento. Una vez instalado, ejecuta el Administrador de Actualizaciones.
