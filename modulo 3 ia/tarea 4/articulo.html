Bot de Discord para Inventario en Tiempo Real

Caso de Uso: Este flujo automatiza la consulta y actualización de stock mediante comandos de barra (`/stock`, `/update`) directamente desde un servidor de Discord. Utiliza un backend en Python (con FastAPI) que sirve como middleware entre Discord y una base de datos PostgreSQL, garantizando que el equipo de ventas siempre tenga acceso a datos precisos sin salir de su plataforma de comunicación.

# Prerrequisitos

  • Acceso a un entorno Linux (Ubuntu 22.04 recomendado).
  • Python 3.10+ y `pip` instalados.
  • Librerías: `fastapi`, `uvicorn`, `discord.py`.
  • Un token de bot activo desde el Discord Developer Portal.
  • Túnel TCP (ej. ngrok) para exponer el puerto local durante el desarrollo.

# Implementación Core

Python 

import discord
from discord.ext import commands
import uvicorn
from fastapi import FastAPI, Request

# Inicialización de instancias
app = FastAPI()
bot = commands.Bot(command_prefix="!", intents=discord.Intents.default())

@app.post("/webhook/discord")
async def discord_webhook(request: Request):
    data = await request.json()
    # Verifica que el JSON contenga una etiqueta (tag) válida, no solo atributos.
    if "type" in data and data["type"] == 1:
        return {"type": 1} # ACK
    
    # Procesamiento del comando
    if data["data"]["name"] == "stock":
        item_id = data["data"]["options"][0]["value"]
        # Lógica de conexión a DB...
        return {
            "type": 4,
            "data": { "content": f"El stock para el item {item_id} es: 45 unidades." }
        }

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)

# Troubleshooting (Depuración)

Error / Síntoma Causa Raíz Solución
[Errno 98] Address already in use Puerto bloqueado en Ubuntu terminal (puerto 8000 ocupado por otro proceso de Uvicorn). Ejecuta lsof -i :8000 y mata el PID con kill -9 <PID>.
401 Unauthorized de Discord API Token caducado o mal configurado en el header de autorización. Regenera el token en el Developer Portal y actualiza el archivo .env.
El estilo no se aplica en el Dashboard Conflicto de etiquetas vs atributos en la vista HTML (ej. usar mal class= en un tag inexistente). Verifica que los selectores CSS coincidan exactamente con los atributos class del DOM.
