Sistema de Gestión de Inventario para Artesanías

> Autor: SysAdmin | Fecha: 2026-10-02 | Tags: [Python, SQLite3, Pandas, ETL, IA]

1. Definición del Problema

Un emprendimiento dedicado a la fabricación de pulseras artesanales de hilo chino (utilizando patrones de nudo plano y nudo franciscano) requiere un sistema robusto para el rastreo de materia prima y productos terminados. La complejidad radica en que cada producto final consume una longitud variable de material base (hilo medido en centímetros) y combinaciones de dijes o cierres.

Llevar esto en una hoja de cálculo estándar genera discrepancias de stock, ya que la venta de una pulsera debe descontar proporcionalmente los centímetros del rollo de hilo maestro. La solución arquitectónica óptima es una base de datos relacional (SQL) gestionada por un motor ligero (SQLite3) con una capa lógica en Python (Pandas) para cálculos masivos y reportes.

2. Modelo Relacional de Base de Datos (Esquema SQL)

El modelo se divide en tres entidades fundamentales: Materiales (Rollos de hilo, cierres, dijes), Productos (Modelos específicos de pulseras y su receta o Bill of Materials) y Ventas (Registro transaccional).

Table: materiales
PK id_material INTEGER
nombre_color VARCHAR(50)
stock_cm DECIMAL(10,2)
costo_por_cm DECIMAL(5,4)
Table: productos (Recetas)
PK sku_producto VARCHAR(20)
nombre_modelo VARCHAR(100)
FK mat_principal_id INT
consumo_hilo_cm INT
Table: ventas_log
PK id_transaccion UUID
FK sku_vendido VARCHAR(20)
fecha_venta TIMESTAMP

3. Lógica Transaccional en Python (Backend)

A continuación, se detalla el script en Python encargado de procesar un archivo CSV de ventas diarias. El script lee las ventas usando pandas, abre un cursor transaccional hacia sqlite3, e itera deduciendo el inventario. Si el stock cae por debajo de cero, la transacción hace un ROLLBACK para garantizar la integridad ACID. 

# /opt/scripts/sync_inventory.py
import sqlite3
import pandas as pd
import logging
from datetime import datetime

logging.basicConfig(level=logging.INFO, format='%(levelname)s - %(message)s')

def procesar_ventas_diarias(csv_path, db_path):
    # 1. Cargar datos del día
    try:
        df_ventas = pd.read_csv(csv_path)
    except Exception as e:
        logging.error(f"Fallo al leer CSV: {e}")
        return

    # 2. Conexión SQLite (Modo transaccional)
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    
    try:
        cursor.execute("BEGIN TRANSACTION;")
        
        for index, row in df_ventas.iterrows():
            sku = row['sku_producto']
            cantidad = row['cantidad_vendida']
            
            # Obtener la receta del producto (consumo por unidad)
            cursor.execute("""
                SELECT mat_principal_id, consumo_hilo_cm 
                FROM productos WHERE sku_producto = ?
            """, (sku,))
            receta = cursor.fetchone()
            
            if not receta:
                raise ValueError(f"SKU {sku} no existe en catálogo.")
                
            mat_id, consumo = receta
            consumo_total = consumo * cantidad
            
            # Descontar del inventario maestro (Rollo de hilo)
            cursor.execute("""
                UPDATE materiales 
                SET stock_cm = stock_cm - ? 
                WHERE id_material = ? AND stock_cm >= ?
            """, (consumo_total, mat_id, consumo_total))
            
            if cursor.rowcount == 0:
                raise ValueError(f"Stock insuficiente para material ID {mat_id}.")
                
            # Registrar la transacción
            cursor.execute("""
                INSERT INTO ventas_log (sku_vendido, fecha_venta)
                VALUES (?, ?)
            """, (sku, datetime.now()))
            
        # 3. Confirmar cambios si todo fue exitoso
        conn.commit()
        logging.info("ETL completado. Base de datos actualizada.")
        
    except Exception as e:
        conn.rollback()
        logging.error(f"Rollback ejecutado. Error transaccional: {e}")
    finally:
        conn.close()

if __name__ == "__main__":
    procesar_ventas_diarias('/var/data/ventas_hoy.csv', '/var/db/inventario.db')

4. Integración de Agente Administrador de IA (Prompt Engineering)

Una vez estabilizada la base de datos SQL, podemos exponer un endpoint RESTful (usando FastAPI) que devuelva un volcado JSON del estado actual del inventario. Este JSON se inyecta dinámicamente como contexto (System Prompt) para un modelo de lenguaje (LLM) como Claude o LLaMA3, creando un "Administrador de Negocio Autónomo".
