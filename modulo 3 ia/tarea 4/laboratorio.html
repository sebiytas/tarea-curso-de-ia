Laboratorio de Bots

Arquitecturas de mensajería asíncrona. Aprende a enrutar comandos desde WhatsApp y Discord hacia tu entorno local mediante Webhooks y Túneles TCP.

# Topología de Red: Localhost to Web

1
📱

Plataforma Emisora

El usuario envía un mensaje por Discord o WhatsApp. La API de la plataforma dispara un evento (Webhook POST).

2
🌐

Túnel Reverso

Ngrok o Cloudflare Tunnels capturan el tráfico público de internet y lo enrutan de forma segura hacia tu máquina local.

3
💻

Middleware Local

Un servidor FastAPI (Python) o Express (JS) en `127.0.0.1:8000` procesa el JSON entrante y ejecuta la lógica de negocio.

Comandos Útiles de Inicialización:

Exponer puerto 8000 (ngrok): ngrok http 8000
Iniciar servidor Python (FastAPI): uvicorn main:app --reload
Monitorear logs en tiempo real: tail -f server.log
