Etiqueta HTML (Tag) vs Atributo HTML (Attribute)

Esta es una distinción fundamental y crítica en el desarrollo Frontend. Confundir estos dos conceptos lleva a errores estructurales severos al manipular el DOM mediante JavaScript.

Etiqueta HTML (Tag): Es la estructura base del elemento en sí. Define *qué* es el elemento en el árbol semántico del documento (un párrafo, un bloque, una imagen). Se encierra entre signos de mayor y menor (< >). Ejemplos: <div>, <p>, <button>.

Atributo HTML (Attribute): Es la información adicional que modifica o configura el comportamiento de una etiqueta. Los atributos siempre viven dentro de la etiqueta de apertura y generalmente tienen la forma nombre="valor". Ejemplos: class="btn", id="submit", src="img.png". 

<!-- Ejemplo Correcto -->
<button class="btn-primary" id="submit-form">Enviar</button>

<!-- 
  Desglose:
  - "button" es la ETIQUETA (Tag).
  - "class" e "id" son los ATRIBUTOS (Attributes).
  - "btn-primary" es el VALOR del atributo class.
-->

Inecuaciones Lógicas (C++)

En C++ (y la mayoría de lenguajes C-like), las inecuaciones lógicas determinan el flujo de control del programa comprobando si un valor cumple una condición matemática con respecto a otro. Los operadores principales son <, >, <=, >=, ==, y !=. 

int x = 10;
int y = 20;

// Inecuación combinada usando AND (&&) y OR (||)
if (x < y && (x + 15) >= y) {
    std::cout << "Condición de umbral cumplida." << std::endl;
}

Consultas SELECT / INNER JOIN (SQL)

El operador INNER JOIN se utiliza para combinar filas de dos o más tablas, basándose en una columna relacionada entre ellas. Devuelve únicamente los registros que tienen valores coincidentes en ambas tablas. 

SELECT p.nombre_modelo, m.nombre_color 
FROM productos p
INNER JOIN materiales m ON p.mat_principal_id = m.id_material
WHERE m.stock_cm < 100.0;
